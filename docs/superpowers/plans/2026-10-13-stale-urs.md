# UR abandonnés et sélection par critères — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the speed-camera tab also close open URs of any type left unanswered for more than 14 days, and let the editor pick with three checkboxes which families the tab handles, behind a single batch button.

**Architecture:** Everything stays in `src/speed-camera-urs/`. A pure predicate (`isStaleCandidate`) picks candidates from the data model, the `Scanner` reads their conversation only when the "abandoned" box is checked, `close.ts` gains `closeStale` and a two-family `closeMany`, and the tab gets a checkbox block, an "Abandoned" section and one batch button. Checkbox state lives in a small versioned `settings.ts` over `localStorage`.

**Tech Stack:** TypeScript, WME SDK (`wme-sdk-typings`), i18next, Vitest (node environment, no DOM), Rollup.

**Spec:** `docs/superpowers/specs/2026-10-12-stale-urs-design.md` (read it before starting; this plan argues from it).

## Global Constraints

- Branch: `feat/stale-urs`, created from `main`. The working tree has unrelated changes (`header-dev.js`, `package.json`, `package-lock.json`, `sitn/`, `.claude/`): **never stage them**. Always `git add` explicit paths.
- Stale criterion: open, editable, `now - reportedOn > 14 days`, description not starting with `MISSING_STATIC_SPEED_CAMERA`, no comment except those whose `userName === "Map_Team"` (exact match; `null` counts as a discussion).
- Stale closure: `not-identified`, **never** `addComment`.
- `STALE_BATCH_MIN_RANK = 3` (displayed level 4). `BATCH_MIN_RANK = 2` unchanged. `BATCH_CAP = 50` for the whole batch, speed cameras first.
- A speed-camera UR is never "abandoned". A `MISSING_TRAFFIC_LIGHT` UR whose closest road is a freeway is never "abandoned"; one elsewhere may be.
- Traffic lights on a freeway: never in any batch. Their checkbox only shows/hides their section.
- Settings key: `wme-ch-speed-camera-urs.settings`, shape `{ version: 1, criteria: { speedCamera, trafficLight, stale } }`, defaults `true, true, false`.
- Batch buttons are **hidden**, not greyed, below the level. Every rank gate in the UI is enforced again in `close.ts`.
- New strings go into **all four** `locales/<lang>/common.json` under `speedCameraUrs`; `i18n.test.ts` fails on a missing key, an untranslated copy or a lost placeholder.
- Comments explain "why"; early returns; no new abstraction layers (see `CLAUDE.md` › Code Style).
- Commits: Conventional Commits, scope `speed-camera-urs`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Nothing is ever saved automatically.

## Review Focus

1. **Corrupted settings** (`{"criteria":{"stale":"yes"}}`, `[]`, `"x"`): a non-boolean must fall back to its default, never turn the abandoned family on. Pinned in Task 2.
2. **Unchecking "Abandoned" on a dense area**: the next scan must stop reading conversations, yet keep verdicts already cached so re-checking is free. Pinned in Task 4.
3. **Unknown rank** (`getUserInfo()` returns `null`): no abandoned batch, no speed-camera batch. Pinned in Task 5.
4. **A UR closed or commented while the single-UR dialog is open**: `closeStale` re-reads and skips, nothing is written. Pinned in Task 6.
5. **`<wz-checkbox>` that renders but emits no usable `change` event**: the boxes would look fine and do nothing. Not testable in Vitest; Task 7 carries a manual check with an exact console snippet and the fallback to remove the `wz-checkbox` branch.

```ts
/** Past this age with nobody but Map_Team in the conversation, the reporter is not coming back. */
export const STALE_AGE_DAYS = 14;

/**
 * Author of the automatic comments WME adds to a UR. They are not a conversation: nobody
 * is waiting for an answer to them. Exact match on purpose: any other spelling is treated
 * as a person, which keeps the UR out of the batch rather than in it.
 */
export const MAP_TEAM_USER = "Map_Team";

const DAY_MS = 24 * 60 * 60 * 1000;

export function ageInDays(reportedOn: number, now: number): number {
  return Math.floor((now - reportedOn) / DAY_MS);
}

/**
 * An open UR old enough to be abandoned, read from the data model alone. The final verdict
 * also needs the conversation (hasDiscussion), which costs a server round trip.
 *
 * Speed cameras are excluded here rather than by the caller: they always get the official
 * message, and must not slip into a family that closes without one.
 */
export function isStaleCandidate(
  ur: UrFields & Pick<MapUpdateRequest, "reportedOn">,
  now: number,
): boolean {
  const description = ur.description ?? "";
  const oldEnough = now - ur.reportedOn > STALE_AGE_DAYS * DAY_MS;
  const speedCamera = description.startsWith(SPEED_CAMERA_PREFIX);
  return ur.isOpen && ur.isEditable && oldEnough && !speedCamera;
}

export function hasDiscussion(
  comments: readonly ConversationElement[],
): boolean {
  return comments.some((comment) => comment.userName !== MAP_TEAM_USER);
}
```

```ts
import { log } from "./log";

/** Which families of UR the tab lists and puts in its batch. */
export interface Criteria {
  speedCamera: boolean;
  trafficLight: boolean;
  stale: boolean;
}

export interface Settings {
  version: 1;
  criteria: Criteria;
}

export const STORAGE_KEY = "wme-ch-speed-camera-urs.settings";

/**
 * Abandoned starts off: checking it reads the conversation of every old UR on screen, one
 * server round trip each, and widens a lot what a single click can close.
 */
export const DEFAULT_CRITERIA: Criteria = {
  speedCamera: true,
  trafficLight: true,
  stale: false,
};

export type SettingsStore = Pick<Storage, "getItem" | "setItem">;

/** Merely touching localStorage can throw (blocked site data, sandboxed frame). */
function browserStore(): SettingsStore | null {
  try {
    return globalThis.localStorage ?? null;
  } catch {
    return null;
  }
}

/**
 * Field by field, and only booleans: a value of the wrong type keeps its default, so a
 * damaged save can never switch the abandoned family on by itself.
 */
export function loadSettings(
  store: SettingsStore | null = browserStore(),
): Settings {
  const criteria = { ...DEFAULT_CRITERIA };
  let saved: unknown = null;
  try {
    const raw = store?.getItem(STORAGE_KEY);
    saved = raw ? JSON.parse(raw) : null;
  } catch (err) {
    log.warn("Could not read the settings, using the defaults", err);
  }
  const savedCriteria =
    typeof saved === "object" && saved !== null
      ? (saved as { criteria?: Record<string, unknown> }).criteria
      : undefined;
  for (const key of Object.keys(criteria) as Array<keyof Criteria>) {
    const value = savedCriteria?.[key];
    if (typeof value === "boolean") criteria[key] = value;
  }
  return { version: 1, criteria };
}

/** A failed save only costs the choice at the next reload. */
export function saveSettings(
  settings: Settings,
  store: SettingsStore | null = browserStore(),
): void {
  try {
    store?.setItem(STORAGE_KEY, JSON.stringify(settings));
  } catch (err) {
    log.warn("Could not save the settings", err);
  }
}
```

### Task 4: Scanner lists abandoned URs

**Files:**
- Modify: `src/speed-camera-urs/scanner.ts`
- Test: `src/speed-camera-urs/scanner.test.ts`

**Interfaces:**
- Consumes: `isStaleCandidate`, `hasDiscussion` (Task 1); `wasMessaged` (existing).
- Produces:
  - `export interface StaleEntry extends TrafficLightEntry { state: "pending" | "stale" }`
  - `ScanSnapshot` gains `stale: StaleEntry[]` (oldest first, like the others)
  - `new Scanner(sdk: WmeSDK, options?: { now?: () => number })`
  - `scanner.setReadStale(on: boolean): void` — sets the flag only; the caller schedules a rescan.

Behaviour: with the flag off, `stale` is `[]` and no stale conversation is read; verdicts already cached are kept. With it on, conversations are read **after** the speed cameras'. A candidate whose conversation shows a discussion disappears from the list. Traffic lights on a freeway are never candidates.

```ts
  async rescan(): Promise<void> {
    const generation = ++this.generation;
    const extent = this.sdk.Map.getMapExtent();
    const onScreen = this.sdk.DataModel.MapUpdateRequests.getAll()
      .filter((ur) => isInExtent(ur, extent))
      .sort((a, b) => a.reportedOn - b.reportedOn);
    const found = onScreen.filter(isSpeedCameraUr);

    const candidates = onScreen.filter(isTrafficLightUr);
    const segments =
      candidates.length > 0 ? this.sdk.DataModel.Segments.getAll() : [];
    const lights = candidates.filter((ur) => isOnFreeway(ur, segments));
    this.trafficLights = lights.map((ur) => this.basics(ur));

    // A traffic light on a freeway stays a traffic light: as "abandoned" it would reach a
    // batch, which that family must never do.
    const lightIds = new Set(lights.map((ur) => ur.id));
    const now = this.now();
    this.staleCandidates = this.readStale
      ? onScreen.filter(
          (ur) => isStaleCandidate(ur, now) && !lightIds.has(ur.id),
        )
      : [];
    this.publish(found);

    for (const ur of found) {
      if (this.triageCache.has(ur.id)) continue;
      const comments = await this.readConversation(ur.id, generation);
      if (comments)
        this.triageCache.set(
          ur.id,
          triage(comments, alreadyMessaged(ur.id, comments)),
        );
      if (generation !== this.generation) return;
      this.publish(found);
    }

    // After the speed cameras: those carry a message the reporter is waiting for.
    for (const ur of this.staleCandidates) {
      if (this.staleCache.has(ur.id)) continue;
      const comments = await this.readConversation(ur.id, generation);
      if (comments) this.staleCache.set(ur.id, !hasDiscussion(comments));
      if (generation !== this.generation) return;
      this.publish(found);
    }
  }

  /**
   * null on failure, absence, or when a newer scan or a change to the UR overtook the read:
   * the UR then stays pending and the next scan retries.
   */
  private async readConversation(
    id: number,
    generation: number,
  ): Promise<ConversationElement[] | null> {
    const version = this.versions.get(id) ?? 0;
    try {
      const details =
        await this.sdk.DataModel.MapUpdateRequests.getUpdateRequestDetails({
          mapUpdateRequestId: id,
        });
      const overtaken =
        generation !== this.generation ||
        version !== (this.versions.get(id) ?? 0);
      return details && !overtaken ? details.comments : null;
    } catch (err) {
      log.warn(`Could not read the conversation of UR ${id}`, err);
      return null;
    }
  }
```

```ts
      trafficLights: this.trafficLights,
```

```ts
/**
 * Close one abandoned UR as not-identified, without any message: the reporter has not
 * looked at it in weeks, and the official text speaks of speed cameras.
 *
 * Re-checks everything right before writing, like closeOne: the list may be minutes old,
 * and a comment arriving since then means someone is talking to the reporter. Same
 * inFlight guard, so a double click does not start two reads.
 */
export async function closeStale(
  sdk: WmeSDK,
  id: number,
  now = Date.now(),
): Promise<CloseOutcome> {
  if (!sdk.Editing.isEditingAllowed())
    return { id, result: "failed", reason: "errNotAllowed" };

  const urs = sdk.DataModel.MapUpdateRequests;
  const ur = urs.getById({ mapUpdateRequestId: id });
  if (!ur || !isStaleCandidate(ur, now))
    return { id, result: "skipped", reason: "skipGone" };
  // Never through this door: traffic lights on a freeway have no batch at all.
  const freewayLight =
    isTrafficLightUr(ur) && isOnFreeway(ur, sdk.DataModel.Segments.getAll());
  if (freewayLight) return { id, result: "skipped", reason: "skipGone" };

  if (inFlight.has(id))
    return { id, result: "skipped", reason: "skipConversation" };
  inFlight.add(id);
  try {
    let comments: ConversationElement[];
    try {
      const details = await urs.getUpdateRequestDetails({
        mapUpdateRequestId: id,
      });
      if (!details) return { id, result: "failed", reason: "errDetails" };
      comments = details.comments;
    } catch (err) {
      log.warn(`Could not read the conversation of UR ${id}`, err);
      return { id, result: "failed", reason: "errDetails" };
    }
    if (hasDiscussion(comments) || wasMessaged(id))
      return { id, result: "skipped", reason: "skipConversation" };
    return closeWithoutMessage(urs, id);
  } finally {
    inFlight.delete(id);
  }
}
```

```ts
/**
 * The batch. Re-checks both ranks itself: a gate enforced only where the button is drawn
 * would be one missed check away from being gone. null when the editor has the rank for
 * none of the families asked for.
 */
export async function closeMany(
  sdk: WmeSDK,
  request: BatchRequest,
  now = Date.now(),
): Promise<CloseOutcome[] | null> {
  const allowed = allowedBatch(sdk, request);
  const asked = request.speedCamera.length + request.stale.length;
  const kept = allowed.speedCamera.length + allowed.stale.length;
  if (asked > 0 && kept === 0) return null;

  const batch = capBatch(allowed);
  const outcomes: CloseOutcome[] = [];
  // One at a time: gentler on the server, and a failure costs one UR rather than a burst.
  for (const id of batch.speedCamera) {
    outcomes.push(await closeOne(sdk, id, { allowConversation: false }));
  }
  for (const id of batch.stale) {
    outcomes.push(await closeStale(sdk, id, now));
  }
  return outcomes;
}
```

```ts
 * The single batch: one line per family, so the editor reads what happens to each, not
 * just a total. The quote and the warning only appear when speed cameras are in it, since
 * they alone send something that cannot be withdrawn.

 * Every language of the batch is offered, not only the editor's: the German or Italian
 * text is what those reporters will read, and the editor should be able to see it before
 * sending it to them.

export function closeSelectedSpec(
  speedCameraLangs: readonly LocaleCode[],
  staleCount: number,
  editorLang: LocaleCode,

  const cameraCount = speedCameraLangs.length;
  const facts: string[] = [];
  if (cameraCount > 0)
    facts.push(t("dlgFactFamilySpeedCamera", { count: cameraCount }));
  if (staleCount > 0)
    facts.push(t("dlgFactFamilyStale", { count: staleCount }));

  const spec: ConfirmSpec = {
    title: t("dlgTitleSelected", { count: cameraCount + staleCount }),
    facts,
    confirmLabel: t(cameraCount > 0 ? "dialogConfirm" : "dialogCloseOnly"),
    cancelLabel: t("dialogCancel"),
  };
  if (cameraCount === 0) return spec;

  const counts = languageCounts(speedCameraLangs);
  // The editor's own language first when the batch has it: it is the one they can proofread.
  const ordered = [
    ...counts.filter((entry) => entry.lang === editorLang),
    ...counts.filter((entry) => entry.lang !== editorLang),

    text: buildMessage(entry.lang),
  }));

    label: t("dlgQuoteLabel"),
    hint: options.length > 1 ? t("dlgQuoteHint") : undefined,
    options,
  };
```

```ts
/**
 * Everything the editor ticked, at once. Each family is filtered by its own rank before
 * anything is asked, and closeMany checks again. When nothing is left, the editor is told
 * which level the request needed.
 */
export async function runCloseSelected(
  sdk: WmeSDK,
  request: BatchRequest,
  prompts: Prompts = {},
  now = Date.now(),
): Promise<CloseOutcome[] | null> {
  const confirm = prompts.confirm ?? confirmDialog;
  const notify = prompts.notify ?? notifyDialog;
  const allowed = allowedBatch(sdk, request);
  const asked = request.speedCamera.length + request.stale.length;
  const kept = allowed.speedCamera.length + allowed.stale.length;
  if (asked > 0 && kept === 0) {
    const minRank =
      request.speedCamera.length > 0 ? BATCH_MIN_RANK : STALE_BATCH_MIN_RANK;
    await notify(t("errBatchRank", { level: minRank + 1 }));
    return null;
  }
  const batch = capBatch(allowed);
  if (batch.speedCamera.length + batch.stale.length === 0) return [];
  // Each closure checks again, but asking the editor to confirm a batch that can only
  // fail is a worse experience than saying so up front.
  if (!sdk.Editing.isEditingAllowed()) {
    await notify(t("errNotAllowedBatch"));
    return null;
  }

  return withCloseLock(async () => {
    const langs = batch.speedCamera.map((id) =>
      messageLanguage(
        sdk.DataModel.MapUpdateRequests.getById({ mapUpdateRequestId: id })
          ?.userPreferences?.language,
      ),
    );
    const accepted = await confirm(
      closeSelectedSpec(langs, batch.stale.length, getLocale()),
    );
    if (!accepted) return null;

    const outcomes = await closeMany(sdk, batch, now);
    if (outcomes) await notify(summarizeBatch(outcomes, batch.speedCamera));
    return outcomes;
  });
}
```
